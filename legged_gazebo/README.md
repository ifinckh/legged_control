# Forest Simulation

This folder contains forest environments for testing legged-robot planners in Gazebo.

## Overview

The forest environments are generated by combining terrain maps produced by `gazebo_terrain_generator` with trees placed on the terrain using a Python script.

The terrain size and heightmap are read from the generated terrain `.world` file, allowing the same generator to be used for different terrain environments.

## Structure

```text
legged_gazebo/
├── launch/
│   └── forest_sim.launch.py
├── models/
│   ├── terrain_01/
│   ├── terrain_02/
│   ├── terrain_03/
│   └── trees/
├── scripts/
│   └── generate_forest_world.py
└── worlds/
    ├── forest_terrain_01.sdf
    ├── forest_terrain_02.sdf
    └── forest_terrain_03.sdf
```

## Generate a forest world

From the workspace root:

```bash
python3 src/legged_gazebo/scripts/generate_forest_world.py --terrain terrain_02
```

This generates the corresponding forest world in `worlds/`.

## Launch

Build and source the workspace:

```bash
cd ~/forma/ros2_ws
colcon build --packages-select legged_gazebo --symlink-install
source install/local_setup.bash
```

Launch a forest environment:

```bash
ros2 launch legged_gazebo forest_sim.launch.py terrain:=terrain_02
```

Available terrains can be selected using the `terrain` launch argument.

## Notes

* Forest generation is performed offline; Gazebo only loads the generated world.
* Trees are currently represented by simple models for simulation and testing.
* The environments are intended primarily for testing navigation and planning algorithms.
